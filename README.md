A make.fun entry for **The Worst App Idea Ever Pitched**: one pitch sentence — 138 characters — for the worst and most useless app idea imaginable. The program writes exactly that pitch to `/output/entry.txt`.

> DustLedger catalogues every dust bunny under your bed, names each one, and charges $3.99 a month to text you the moment one of them moves.

A product that sounds real, a founder who sounds certain, a function nobody on earth needs. The $3.99 anchor makes it sound like a real subscription — and the alert fires for an event that effectively never happens, so the app diligently monitors nothing, forever, for money.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
